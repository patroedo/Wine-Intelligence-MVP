# Cellarion comparison experiment

Goal: evaluate Cellarion architecture and wine-registry matching for Wine Intelligence MVP.

## What we test
1. Wine registry and fuzzy matching
2. Producer/name/appellation deduplication
3. Import matching
4. Label scan interface and provider abstraction
5. Drink history / cellar UX concepts
6. Deployment complexity and licensing implications

## Acceptance test
Same Giacomo Conterno / Barolo Monfortino image and scorecard as other candidates.
